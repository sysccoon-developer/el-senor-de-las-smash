# ⚔️ El Señor de las Smash — Web App & Cotizador de Eventos

> *"Una smash burger para gobernarlas a todas."*

Aplicación web oficial de **El Señor de las Smash** (León, Guanajuato), diseñada con una estética de taberna medieval oscura y metálica. Permite explorar el menú artesanal, consultar promociones vigentes y calcular cotizaciones interactivas en tiempo real para eventos privados con envío directo a WhatsApp.

---

## ✨ Características Principales

- **Menú Interactivo:** Catálogo estructurado de hamburguesas artesanales, complementos y bebidas con pedido directo por WhatsApp.
- **Cotizador Dinámico de Eventos:** Calculadora en tiempo real con paquetes escalonados (*Escudero*, *Caballero* y *Monarca*) a través de distintas líneas de producto, desglose transparente de tarifa operativa fija + costo por invitado y envío de propuesta prellenada.
- **Galería y Promociones:** Vista filtrable con *lightbox* para exhibición de platillos, montajes en eventos y promociones activas.
- **Navegación & UX Temática:** Barra lateral responsiva con iconografía personalizada (`Swords` / `Shield`), restauración automática de scroll (`ScrollToTop`) y página 404 temática de la forja.
- **Despliegue Automatizado:** Pipeline CI/CD mediante GitHub Actions con soporte para enrutamiento SPA (`404.html` fallback) y distribución vía Cloudflare CDN.
